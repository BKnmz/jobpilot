Get started

Up and running in 3 minutes

Windows only (scraper uses Microsoft Edge). Python 3.11+ required.

Option A — One click

Download the repo and double-click run.bat. It installs all dependencies and launches the app automatically.

⬇ Download ZIP

Option B — Git clone

Clone the repo and run the setup commands below.

# Clone
git clone https://github.com/YOUR_USERNAME/jobpilot.git
cd jobpilot

# Install deps
pip install -r requirements.txt
playwright install chromium

# Configure your CV
cp master_cv.example.md master_cv.md

# Launch
streamlit run app.py

Then open ⚙️ Settings in the app to paste your Gemini API key.
